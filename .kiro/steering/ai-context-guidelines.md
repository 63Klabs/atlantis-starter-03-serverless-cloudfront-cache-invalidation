# AI Development Context & Guidelines

This steering document ensures that all AI agents working in this repository follow the established architectural principles, constraints, naming conventions, and deployment workflows.

The complete context and guidelines are maintained in the root-level AI_CONTEXT.md file:

#[[file:AI_CONTEXT.md]]

## Key Reminders for AI Agents

When working in this repository, always remember:

1. **Serverless-First Architecture**: Use AWS Lambda, EventBridge, S3, DynamoDB, and other managed services
2. **Naming Conventions**: All resources must follow `Prefix-ProjectId-StageId-Resource` format
3. **IAM Security**: Always use least privilege with resource-scoped permissions - never AWS managed policies
4. **No Platform Modifications**: Never modify Atlantis platform templates or shared infrastructure
5. **Testing Requirements**: Include unit tests and property-based tests where appropriate
6. **Deployment Workflow**: Use only the established CI/CD pipeline, never manual deployments
